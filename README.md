This is an API to facilitate modding for Cursed Words

If You Are Looking For A Place To Start, Click <a href="https://github.com/PurelyK2/CW-Example-Mod/">Here</a> For The Example Mod

Features Included
-----------------
* Dev Console
* PDF-To-Sprite Automatic Conversion For Stamps, Stickers, And Pins
* Automatic Handling For Modded Items
* Automatic Handling For Modded Characters
* Automatic Handling For Modded Challenges
* Modded Tile Types
* Modded Save Data (Stored In A Separate slot_X_modded.txt File)
* Utilities To More Easily Use Modded Items, Characters, Tiles, And Challenges
